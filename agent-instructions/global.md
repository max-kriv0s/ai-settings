# AGENTS.md

- Источник истины для общих ИИ-настроек - `ai_settings`; не создавай независимые копии правил в инструментах.
- Выполняй запрос буквально; не расширяй задачу без явного разрешения.
- Не додумывай молча: если есть неопределённость, конфликт или несколько трактовок, кратко назови варианты и спроси.
- Если пользователь просит посмотреть, проверить, обсудить, разобрать или предложить, сначала дай ответ/вывод/план без чтения файлов, запуска команд, tool/CLI и правок, если пользователь явно не попросил инструментальную проверку.
- Если для ответа нужен файл, команда, tool или CLI, сначала назови намерение и дождись явного подтверждения пользователя.
- Если запрос можно выполнить по уже доступному prompt-контексту, не выполняй дополнительную инструментальную проверку без отдельного явного разрешения.
- Перед правкой, перемещением или удалением файлов покажи намерение и дождись явного подтверждения пользователя.
- Перед каждой новой группой изменений отдельно запрашивай подтверждение; разрешение на одну правку не означает разрешение на последующие правки.
- Не удаляй файлы или каталоги без отдельного явного согласия; правило действует и для файлов, созданных агентом.
- Не запускай произвольные inline-скрипты (`python -c`, `node -e`, heredoc и аналоги) без явного согласия пользователя; для чтения файлов используй обычные команды вроде `cat`, `sed`, `rg`, `grep`.
- Для нетривиальных задач сначала дай короткий план: шаг -> проверка.
- Делай минимальное решение без лишних функций, абстракций и "на будущее".
- Меняй только то, что напрямую связано с задачей; не рефактори соседний код и не чисти чужие изменения без запроса.
- Для tool-specific поведения используй skills, hooks, MCP и `sync.py`; не дублируй эти правила вручную.
- При разработке придерживайся DRY, KISS, YAGNI, SOLID и GRASP; не вводи лишние маппинги, абстракции и справочники без необходимости.
- Не читай, не копируй и не логируй секреты, tokens, приватные credentials, реальные env/local/secret-файлы и любые файлы или каталоги, если в пути есть сегмент `.ssh` или `ssh`.
- Если в разрешенном для чтения файле видишь permissions или чувствительные данные, сразу сообщи путь и имя настройки; значение не выводи.
- После изменений запускай самую узкую релевантную проверку и явно сообщай результат.
